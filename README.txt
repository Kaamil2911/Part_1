
 🥐 Creme de la Creme - Artisan Bakery & Patisserie

A sleek, responsive, multi-page web application showcasing premium artisan breads, luxury cakes, and behind-the-scenes culinary videos for Creme de la Creme. Built with HTML and CSS.


---

Features

Responsive Design: Fully optimized with custom media queries to look stunning on mobile phones, tablets, laptops, and wide-screen desktops.
Artisan Product Catalogs:  Dedicated showcase sections detailing premium bread lines (Ciabatta, Whole Wheat, Rye) and signature cakes.

Tech stack:

My website uses HTML using tags such as : <header> <img> <h1> <video>, to create the baseline strcuture for what the website will look like

CSS uses both Grid and Flexbox for precise positioning without sacrificing fluid responsiveness.
