
Crème de la Crème — Artisan Bakery & Patisserie

A sleek, responsive, multi-page web application designed to showcase premium artisan breads, luxury cakes, and behind-the-scenes culinary videos for Crème de la Crème.

---

Features

- Fluid Responsive Design:   Fully optimized with custom CSS media queries to ensure a seamless experience across mobile devices, tablets, laptops, and ultra-wide desktops.
- Artisan Product Catalogs:  Dedicated, highly structured showcase grids for premium bread lines (Ciabatta, Whole Wheat, Rye) and signature luxury cakes.
- Immersive Media:   Integrated high-definition HTML5 video cards highlighting the bakery's state-of-the-art ovens and traditional hand-kneading techniques.
- Dynamic UX Features:   Includes an interactive Leaflet map integration for store locations, a client-side search filtering system, and an interactive Lightbox gallery.
- SEO Optimized:  Unique, page-specific meta tags and canonical URLs configured for enhanced search engine visibility.

---

Tech Stack & Architecture

HTML5 Semantic architecture utilizing clean structure tags including `<header>`, `<main>`, `<section>`, `<video>`, and properly optimized `<img>` elements with descriptive alt text.
CSS3 (Grid & Flexbox):  Hybrid layouts utilizing CSS Grid for overall page structures/product catalogs and Flexbox for precise, alignment-critical positioning (navigation bars, footers, and video cards) without sacrificing fluid responsiveness.
JavaScript :  Vanilla JavaScript powering dynamic UI components, including form validation, interactive search filtering, and Lightbox modal behaviors.
